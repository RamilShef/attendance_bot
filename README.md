# Attendance Bot

Telegram-бот для учёта посещаемости студентов. Позволяет регистрироваться, отмечать присутствие/отсутствие и просматривать статистику. Администратор может управлять всеми студентами и получать сводку за день.

## Возможности

- Регистрация студента по ФИО.
- Отметка собственного присутствия (для обычных пользователей).
- Администратор:
  - Отмечает себя и любого студента.
  - Может отметить всех сразу через удобное подменю.
  - Просматривает статистику за сегодня.
  - Удаляет студентов и сбрасывает отметки.
- Кнопки-инлайн для быстрого взаимодействия.
- Хранение данных в SQLite.

## Технологии

- **Rust** + **tokio**
- **teloxide** — фреймворк для Telegram Bot API
- **SeaORM** — ORM для работы с базой данных
- **SQLite** — хранилище данных
